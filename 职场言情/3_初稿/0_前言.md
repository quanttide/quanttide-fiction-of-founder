# 前言

有天晚上，我在便利店写完了男女主久别重逢后的第一次谈心。

他们坐在靠窗的位置，各捧一杯热饮。窗外是零下的城市，窗内是两个人呼出的白气。那个情节我写了很久，也改了很久，因为太多话想借着他们的口说出来，写到后来，自己反而不知道还能再说什么。

我在各种尝试中持续地茫然，被现实的压力推着往前走，常常不知道自己在碰什么。可写作这件事慢慢变成了一个持续补充心力的安全空间。

每当夜晚的恐惧漫上来，害怕一切不会好起来，害怕心里的话永远说不出口，我就回到这个虚构的世界里，写一点，再写一点。

这个故事的设定是一个典型的母题：双向暗恋、久别重逢。

但在最关键的走向上，我刻意回避了“破镜重圆”。这份不讲道理的等待，成了整部小说最大的悬念——他们凭什么还能记住彼此？他们为什么愿意等十年？

我渐渐发现，我想写的故事是：我们不需要回到过去，我们现在就可以重新认识一次。

写作的过程，比我想象中更诚实地改变了我。

我原本计划写他们重逢时是欢快的，但写着写着，环境变热闹了，氛围反而变得文艺。现实里说不出口的那些烦恼——不敢说，不敢写，也不相信有人能理解——被放进故事里，被男女主的对话承接住，却获得了某种自由。

我在这部小说里放了很多真实的东西。

“瓶子”这个意象，来自一个曾经有过纠缠的女孩。那不是一个愉快的经历，但那个形容太深刻了，深刻到我不知道该怎么写。于是我把这些感受写下来，先让自己看到这些情绪的形状。后来我才明白，释怀是故事有了不同的意义，而我可以继续向前，而不是让情绪停留在原地。

那段十年重逢，是我想让男女主去完成的执念——我曾经有过的，大概很多人也有过的，那种被看见的渴望。

写着写着，我越来越敢去触碰那些更深的主题，也越来越多地把真实的幽微感受放进故事里。

每一次写完，把段落读出来，那些焦虑就随之放下了。

写作教会我的最重要一件事是：把不敢说的，变成可以说的。

我渐渐发现，这部小说不是一座可以装下一生的容器。它装下的只是我写作这半年来的困惑、恐惧、孤独与勇气。小说里的十年，是我回顾过去的十年。十年之前是意气风发，十年之后是无数的现实压力在困扰。

我选择把真实的职场体悟写进男女主的人设里，是因为他们的故事原本就有一部分继承自我的意志。那些无法公开表达的情绪，被我放进了更隐晦的批评、更直白的感受里。

这不仅仅是一部小说。

是我决定让自己不再停留在原地。
